# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Одностраничный статичный сайт-приглашение на свадьбу (Святослав и Ксения, август 2027). Никакой сборки, зависимостей или бэкенда — чистые `index.html` / `styles.css` / `script.js`, открываются прямо в браузере или заливаются как есть на статичный хостинг (GitHub Pages / Netlify / Vercel — конкретный хостинг ещё не выбран).

Нет package.json, нет тестов, нет линтера — команд сборки/тестирования не существует. Для локальной проверки достаточно открыть `index.html` в браузере (или поднять любой статичный сервер, например `npx serve`).

## Архитектура

- `index.html` — вся разметка одной длинной страницы, секции идут последовательно сверху вниз: hero-фото → приглашение → обратный отсчёт → место проведения → анкета гостя → дресс-код → пожелания по подаркам → закрывающая секция.
- `styles.css` — все стили страницы, без CSS-модулей/препроцессоров. Цветовая палитра завязана на три фона секций: `--maroon` (#2a0c16), `--dark` (#120a0d), `--green` (#0c241d) — переиспользуются между секциями, при добавлении новой секции подбирать один из этих трёх фонов, а не изобретать новый.
- `script.js` — вся интерактивность на чистом JS без фреймворков:
  - обратный отсчёт до `TARGET_DATE` (см. константу вверху файла — при переносе даты свадьбы менять только её);
  - кастомные радио-группы и чекбокс-группы (`.option-group[data-type="radio"|"checkbox"]`) — состояние хранится в объекте `state`, синхронизация с DOM через классы `.selected`, без нативных `<input type="radio">`;
  - отправка анкеты гостя через `fetch` на `SHEETS_ENDPOINT` — сейчас это пустая строка-заглушка, реальный URL Google Apps Script веб-приложения ещё предстоит туда вставить (ответы должны попадать в Google-таблицу без своего бэкенда).
