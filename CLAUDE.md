## Project

Одностраничный статичный сайт-приглашение на свадьбу (Святослав и Ксения, 14 августа 2027, площадка «Пушкинская усадьба»). Никакой сборки, зависимостей или бэкенда — чистые `index.html` / `styles.css` / `script.js`, открываются прямо в браузере или заливаются как есть на статичный хостинг.

Хостинг: приватный репозиторий `DeanRick/slava-ksenya` на GitHub, деплой на Netlify (подключён через GitHub-интеграцию, publish directory — корень, build command не нужен).

Дизайн синхронизируется из проекта claude.ai/design через инструмент DesignSync (см. `DesignSync.get_project`/`list_files`/`get_file` с `projectId: 2c70076e-742f-4fb9-b940-d0b551025ca0`, файл `Приглашение.dc.html`). Это одностороннее чтение — если пользователь просит «подтянуть правки из дизайна», нужно заново вычитать `.dc.html` оттуда и вручную перенести изменения в обычный HTML/CSS/JS (авто-синка нет).

Нет package.json, нет тестов, нет линтера — команд сборки/тестирования не существует. Для локальной проверки достаточно открыть `index.html` в браузере (или поднять любой статичный сервер, например `npx serve`).

## Архитектура

- `index.html` — вся разметка одной длинной страницы, секции идут последовательно сверху вниз: hero-фото → приглашение → обратный отсчёт → место проведения (фото-фон) → детали → анкета гостя → дресс-код → закрывающая секция с контактами организатора.
- `styles.css` — все стили страницы, без CSS-модулей/препроцессоров. Цветовая палитра завязана на фоны секций: `--maroon` (#2a0c16), `--dark` (#120a0d), плюс `--photo` (секция с фоновым фото + затемняющий градиент `.section-bg-overlay--green`) — переиспользуются между секциями, при добавлении новой секции подбирать существующий вариант, а не изобретать новый.
- `script.js` — вся интерактивность на чистом JS без фреймворков:
  - обратный отсчёт до `TARGET_DATE` (см. константу вверху файла — при переносе даты свадьбы менять только её);
  - кастомные радио-группы (`.option-group[data-type="radio"]`) — состояние хранится в объекте `state`, синхронизация с DOM через классы `.selected`, без нативных `<input type="radio">`;
  - алкоголь — одиночный выбор с раскрывающимися подблоками: выбор «Вино» показывает `#wine-block` (цвет + сухость), «Крепкие напитки» — `#spirit-block` (вид напитка), логика в `updateAlcoholBlocks()`;
  - вопрос про конкурс «Карандаш-бутылка» намеренно шуточный (`data-pencil-joke="true"`) — клик по варианту «Нет» реально записывает «Конечно, да!»; это сохранено из оригинального дизайна, не «баг»;
  - отправка анкеты гостя через `fetch` на `SHEETS_ENDPOINT` — сейчас это пустая строка-заглушка, реальный URL Google Apps Script веб-приложения ещё предстоит туда вставить (ответы должны попадать в Google-таблицу без своего бэкенда).
